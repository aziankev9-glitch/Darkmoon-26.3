# Darkmoon Lite — Minecraft Java 26.3

Experimental Fabric client mod, **not yet feature-complete**.

## Build
Open GitHub Actions → Build Darkmoon 26.3. After a successful run, download the artifact and extract the JAR into the Minecraft Fabric mods folder.

## Status
The `/darkmoon` command and four toggle commands are prototypes only. X-Ray rendering, AutoFish, vanilla-style settings UI, and Creative server-side functionality are **not implemented**. Fly and Creative cannot bypass server restrictions.

A successful compile does not mean all gameplay features work.
